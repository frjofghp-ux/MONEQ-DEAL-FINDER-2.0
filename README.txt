MONEQ DEAL FINDER - 무료 MVP

포함 파일
- index.html: 웹앱
- manifest.webmanifest: 홈 화면 설치 정보
- sw.js: 서비스 워커 기본 파일

현재 동작
- 매물 수동 등록 및 예상 차익 계산
- 키워드/가격/플랫폼 알림 조건 저장
- 브라우저 알림 권한 요청 (앱이 열린 상태에서 등록된 매물 조건 충족 시)
- 사용자가 복사한 플랫폼 검색 URL 열기
- 브라우저 localStorage에 데이터 저장

중요한 제한
이 버전은 당근/번개장터의 전체 매물을 자동 수집하지 않습니다. 두 플랫폼이 허용하는 공식 API/파트너 연동 권한이 확인되기 전에는 자동 수집·백그라운드 알림을 제공할 수 없습니다. iOS에서 웹 푸시를 쓰려면 HTTPS 배포, 홈 화면 추가, 웹 푸시 서버 및 사용자 동의가 별도로 필요합니다.

아이폰 설치
1) HTTPS로 배포
2) iPhone Safari에서 접속
3) 공유 > 홈 화면에 추가
4) 앱을 열고 알림 권한 허용

파일을 더블클릭해 로컬에서 테스트할 수 있지만, 설치/알림 기능은 HTTPS 배포 환경을 권장합니다.
